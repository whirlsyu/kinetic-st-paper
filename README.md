# KineticST Paper Analysis Scripts

Analysis scripts for the KineticST manuscript: benchmarking, figure generation, and supplementary analyses.

## Scripts

- `comprehensive_analysis.py` — Main benchmark: 15 supervised marker methods + 5 unsupervised spatial clustering methods across 25 datasets
- `make_extra_figs.py` — Additional figures (runtime, metric scatter, spatial maps)
- `make_individual_figs.py` — Individual dataset spatial domain maps
- `make_otmode_figs.py` — OT-mode specific figures
- `asymmetry_analysis.py` — Asymmetry analysis
- `run_asymmetry_analysis.py` — Runner for asymmetry analysis
- `make_fig9_e8.py` — Figure 9: SOTA comparison panels (STAGATE/SpaGCN/SpaceFlow/BayesSpace/GraphST)
- `analysis_new_platforms.py` — New-platform analysis (MERFISH, seqFISH+, Slide-seqV2)
- `analysis_seqfish.py` — seqFISH+ specific analysis
- `check_sota_api.py` — SOTA method API compatibility check

## SOTA Comparison (experiments/)

- `run_e8_sota_official.py` — Run official implementations of STAGATE, SpaGCN, SpaceFlow, GraphST on all 25 samples
- `run_stagate_only.py` — STAGATE-specific runner
- `run_bayesspace.R` — BayesSpace official R implementation
- `export_e8_bayesspace.py` — Export data for BayesSpace
- `save_e9_sota_labels.py` — Save SOTA method labels for evaluation
- `summarize_e8.py` — Summarize E8 SOTA comparison results
- `merge_e2_stagate.py` — Merge STAGATE results
- `run_e3_independent_simulation.py` — Independent simulation benchmark

## Package

Baseline methods (DEIM+NMF, HVG+NMF, PCA+KMeans, supervised DEIM/mRMR/Laplacian/RF/LR-L1) are provided by the `spatial_nmf_deim` package:

```bash
pip install git+https://github.com/whirlsyu/spatial_nmf_deim.git
```

Or clone separately: https://github.com/whirlsyu/spatial_nmf_deim

## Requirements

```bash
pip install kinetic-st numpy scipy scikit-learn matplotlib
```

## Usage

```bash
python comprehensive_analysis.py
```

## Data

Place your dataset files in a `dataset/` directory or update `DATA_DIR` in the scripts.

Expected datasets:
- Simulated data (generated by `kinetic_st` simulator)
- STSP human brain sections (Visium)
- MOSTA mouse embryo sections (Stereo-seq)
- mouse_E11.5_heart sections (Stereo-seq, 3D reconstruction)
